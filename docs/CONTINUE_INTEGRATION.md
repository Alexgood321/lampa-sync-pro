# Единое продолжение Lampa: Sync Pro 0.1.8 + NUM Series Pro 2.0.7

## Архитектура

Lampa Sync Pro (Alexgood321/lampa-sync-pro) владеет Supabase Auth, защищённым транзакционным RPC, локальной offline-очередью, Realtime WebSocket и кнопкой продолжения на карточке. NUM Series Pro (Alexgood321/lampa-plugins/num_series.js) остаётся отдельным интерфейсом сезонов и серий и использует общий API LampaSyncPro.getEpisodeState/getResume/markEpisode/onChange.

Оригинальный ARST113 «Продолжить просмотр» не отключён автоматически. Его историю не перезаписываем и не удаляем. После E2E-тестирования собственного решения его можно отключить, чтобы убрать дубликаты кнопок.

## Схема работы

1. Подтверждённый запуск торрентного файла или встроенного онлайн Lampac создаёт событие started, в котором серия и источник связаны с ID карточки.
2. Для онлайн Lampac в Supabase попадает только проверенный набор метаданных: balanser, voice_id, voice_name, season_index, voice_index. Ссылки на потоки и секреты не сохраняются.
3. Realtime передаёт уведомление о ревизии, другое устройство забирает актуальный snapshot.
4. На карточке одна собственная кнопка Sync Pro **сразу после зелёной Play в видимой панели**. Для торрента восстанавливается файл и плейлист TorrServer, при временной неготовности `file_stats` выполняется автоматическое чтение с ограниченными задержками (максимум семь запросов, одна попытка добавить hash), для Lampac восстанавливаются провайдер, озвучка и серия.
5. NUM получает облачные completed/reset и применяет к отображению, не затирая нативный Timeline. Ручные массовые отметки из NUM отправляются по одной записи на эпизод с дедупликацией по файлам.
6. Позиция просмотра синхронизируется только там, где реальный плеер передал сведения. Для внешних VLC и IINA на iOS/Mac точный таймкод не гарантирован.

## Импорт прежней истории

В настройках Lampa Sync Pro появилась команда «Импортировать историю „Продолжить“». Это исключительно ручной односторонний импорт из локального ключа lampac_resume_history_v1, максимум 50 фильмов/сериалов за вызов. Существующие облачные записи не заменяются. Исходный ARST-ключ не модифицируется. Отсутствующие идентификаторы и неподдерживаемые источники пропускаются. Magnet-параметры и приватные потоковые URL исключаются из базы.

## Перед отключением ARST

1. Обновить Sync Pro и NUM из My Store, перезапустить Lampa и проверить Realtime: connected.
2. Проверить кнопку для конкретного торрентного файла между двумя устройствами.
3. Проверить онлайн Lampac: тот же провайдер, озвучка и серия на другом устройстве.
4. В NUM отметить сезон, проверить другой экран, отменить отметки, снова проверить.
5. Отдельно импортировать историю ARST и убедиться в сохранности ранее синхронизированных записей.
6. Только после этого отключить ARST и убедиться в отсутствии дублирующей кнопки.
